## Why
Make the tested native trainer available as an inviting public website with mobile input, receiving tools, accounts and synchronized progress.
## What Changes
- Extract the shared Rust core and expose WASM browser/server interfaces without changing native binary records or cw-policy-v1.2.
- Add a responsive Monaspace learning studio, adaptive sessions, receiving toolkit, comparable progress and account settings.
- Serve static assets free on Cloudflare at dojo.veryshyjelly.in; host account/sync API and SQLite on the existing Termux Debian environment behind Tunnel at dojoapi.veryshyjelly.in.
## Impact
Native CLI remains supported. New web envelopes separate keyboard/touch and guided/tool evidence. Google/GitHub OAuth needs owner configuration. Existing phone services and root-domain records are preserved. Physical timing and learning effectiveness remain unverified.
