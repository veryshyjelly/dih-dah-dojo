## Why
The studio currently uses Neon for every role. The researched Monaspace families
can give its welcoming voice, instruments, explanations and coaching distinct
identities while keeping literal practice material stable.

## What Changes
- Introduce a semantic four-family typography system, with scoped accent roles.
- Self-host pinned, unmodified official WOFF2 assets; use static cuts for the two
  occasional accents and retain the existing critical-font preload.
- Preserve controls, practice text, scoring, audio and account data.
- Verify real font loads, both themes, compact layouts and practice interactions.

## Impact
Presentation, font assets and documentation only. No application dependencies,
backend changes or physical timing claims.
