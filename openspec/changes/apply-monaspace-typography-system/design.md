## Roles
- Neon: everyday UI, instrument labels, numeric pace and progress values, and
  literal Morse responses/transcripts.
- Argon: main headings, card titles, overlines and card labels.
- Xenon Regular: introductory prose and help explanations.
- Radon Medium: brief, explicitly selected coaching accents.

Define family tokens and a scoped typography stylesheet. Literal practice data
uses Neon with contextual/coding ligatures disabled. Keep weight, spacing and
layout behavior unless visual review identifies a concrete correction.

Use unmodified v1.400 variable Neon and Argon assets and static Xenon Regular/Radon
Medium cuts. These retain the OFL names/license and need no synthetic weights
for their scoped roles. Font requests remain same-origin and CSS-driven. Only
Neon is preloaded. Version new filenames.

Fonts are presentation-only. Do not change response timing, playback, disclosure,
training policy, history or account state. The physical timing gate remains open.
