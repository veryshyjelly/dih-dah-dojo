## Technical Approach
Keep legacy character scheduling unchanged. Add an explicit token compiler that
recognizes angle-bracket procedural tokens as single units; elements inside a
token have one-dot gaps even when Farnsworth spacing is selected. Ordinary letter
and word gaps retain existing timing. Worklet preparation opts into token mode;
render callbacks retain their current allocation-free behavior.

The canonical catalog includes BT, AR, SK, AS, HH, KN and researched VE/CT signals.
BT and AR share their waveforms with existing = and +. Accept these aliases in
sound recognition and explain their distinct written uses. KN is explicitly the
joined amateur convention. BK, CQ, DE, TU, CL and Q-codes are discussed as operating
abbreviations, not silently collapsed into universally joined tokens. K remains
an ordinary single-letter invitation to transmit. Context examples are original
teaching material, not a single universal QSO script.

Three exercise modes measure different tasks: identify a sound, recall its meaning,
and choose the suitable signal for an operating situation. Transmitted targets and
patterns stay hidden until disclosure. Token answers use complete submissions,
not character recognition's immediate first-key capture. Replays/reveals mark
assistance; unknown is an independent miss. Immutable trial revisions retain the
first answer and later repair. Progress groups revisions without double counting.

Use a separate versioned CWPROS01 binary packet and kind=prosign, dispatched by
existing language codec methods. Existing account-scoped activity transport,
backup frame 2, reset and import therefore preserve this activity. Validation
regenerates canonical items from versioned IDs. Unknown future packets remain
exportable without interpretation. Context includes mode, selected signals,
corpus/version, input profile and character/effective pace. Latency is typing-inclusive
and requires eight independent correct nonnegative samples; no extrapolated trends.

Public references require no account. Personal practice and progress use existing
account gating. Focus/filter/audio state remains outside persisted guided learner
state. All audio stops on navigation, interruption or superseded requests.
