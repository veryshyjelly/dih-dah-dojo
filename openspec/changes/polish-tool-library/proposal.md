## Why
Tools currently opens its third option despite Word training appearing first. The
story library gives speed fields and character lists too much visual weight,
leaving the stories difficult to browse.
## What Changes
- Default Tools to its first option, Word training.
- Give stories a clear editorial hierarchy with short descriptions, compact pace
  controls, word/time metadata, and visible listening actions.
- Keep character coverage in optional disclosures, with progress when available.
- Preserve hidden transmission text and existing player/scoring behavior.
## Impact
Web presentation and default tool selection only. No backend, content, timing,
scoring, history, or native schema changes. The physical timing gate remains open.
